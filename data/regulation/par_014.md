# Párrafo 14

**Sección:** 4.2 Requisitos de los datos

**Subsección:** 4.2.1 Calidad de los datos

En la cuantificación de varios parámetros de riesgo dentro de un sistema de rating, las entidades aplicarán la misma definición de default a las mismas observaciones históricas utilizadas en diferentes modelos. Las entidades, además, aplicarán el mismo tratamiento de múltiples defaults del mismo deudor o exposición en todas las fuentes de datos internos, externos y agrupados.
