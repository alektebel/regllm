# Párrafo 81

**Sección:** 5.3 Calibración de la PD

**Subsección:** 5.3.4 Tasa de default media a largo plazo

A los efectos de los párrafos 79 y 80, las entidades calcularán las tasas de default medias observadas como la media aritmética de todas las tasas de default a un año calculadas conforme a los párrafos 73 a 76. En el caso de los modelos de PD utilizados para las exposiciones minoristas, las entidades podrán calcular la tasa de default media observada como una media ponderada de las tasas de default a un año cuando la entidad no conceda la misma importancia a los datos históricos porque los datos más recientes prevén mejor las pérdidas, conforme al artículo 180, apartado 2, letra e), del Reglamento (UE) n.o 575/2013.
