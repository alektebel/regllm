# Párrafo 79

**Sección:** 5.3 Calibración de la PD

**Subsección:** 5.3.3 Cálculo de la tasa de default media observada

Las tasas de default a un año medias observadas («tasa de default media observada») se calcularán para cada grado o conjunto de rating y también para el tipo de exposiciones cubiertas por el modelo de PD correspondiente así como para cualquier segmento de calibración pertinente.
